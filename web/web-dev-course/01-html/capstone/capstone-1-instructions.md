# Instructions for Capstone Project 1 — Online Resume

## Project Specifications

1. Create an HTML file named `index.html`.
2. Use the `<!DOCTYPE html>` declaration at the beginning of the file to indicate that it's an HTML document.
3. Create a **head** section that includes a **title** element with the text `My Resume`.
4. Inside the **body** section, write HTML for an online resume covering:
   - Summary or objective statement
   - **Education** (degrees, schools, dates)
   - **Work experience** (job titles, employers, dates, responsibilities)
   - **Skills** (relevant skills or areas of expertise)
   - **Awards, certifications, or other achievements**
5. Use appropriate HTML tags for each section (e.g. `h1` for section headings, `ul` or `ol` for lists).
6. Use HTML to add a **profile photo**.
7. Use **anchor tags** to build a multi-page site (e.g. **Hobbies**, **Contact**).
8. Add a **footer** with your name and any copyright or disclaimers.  
   Hint: [MDN — `<footer>` element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/footer)
9. Save `index.html` and open it in a browser to confirm it displays correctly.
10. Add the site to **GitHub** for your portfolio.
11. **Publish** with GitHub Pages and share the link in the Q&A with other students.
12. Comment and suggest improvements on other students’ projects.

- Use **HTML only** for this project. Even if you know CSS/JS, stick to HTML for scope.
- Work like a professional: when you hit limits, use Google, [MDN](https://developer.mozilla.org/), and other docs.

## FAQs

### 1. Can I use these Capstone projects in my job interviews?

Yes. Capstone projects are meant to be **your own work**—no solution code, walkthrough, or design specs—unlike earlier course projects that many students share. That makes them strong portfolio pieces.

When hiring, portfolios and what candidates built themselves often matter more than school or degree alone; many hiring leaders feel the same.

### 2. What if I don't remember how to do something, even though I watched all the videos?

Videos alone often aren’t enough. Capstones are a good way to find gaps. When you’re stuck, revisit earlier lessons or documentation to fill them in.
